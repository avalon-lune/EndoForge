# EndoForge 第四阶段：形变、曲面试件、动作回放与状态记录

本版本用于验证基础形变系统，并为后续胆囊局部场景与视频／几何数据生成做准备。包含平面、简单曲面试件和原有双器械；暂不包含缝合。曲面试件不是胆囊解剖模型，材料与接触参数也没有经过真实组织标定。

## 启动

完整解压后双击 `StartTrainer.cmd`。无需 UE 编辑器、Blender、Python、完整 SOFA SDK或实体器械。支持 Windows x64、DirectX 11；如缺 Visual C++ 运行库，使用包内 `Engine/Extras/Redist/en-us/vc_redist.x64.exe`。

本阶段使用本机 `127.0.0.1:47325`。端口占用时启动器会退出，不会停止其他程序。`F10` 或关闭窗口结束会话，启动器随后关闭本次创建的物理进程。请从启动器进入，不要单独打开内部游戏 EXE。

## 建议试用顺序

1. 按 `4` 选择平面，按 `2` 让器械前往抓持准备位置，等待到位。
2. 让自由边进入钳口，按 `F` 保持闭合；确认有效抓持后用 `Ctrl+W` 缓慢牵拉，再按 `F` 释放。
3. 按 `5` 换曲面，重复观察抓持、牵拉与释放。
4. 按 `F5` 从复位状态开始记录，完成一段操作，再按 `F5` 停止。按 `F6` 回放，期间不要试图用移动键改变记录中的轨迹。
5. 按 `F7` 保存冻结状态快照，查看画面与几何、相机数据的对应。回放和快照测试不等于完整视频／深度／分割数据集导出。保存的单次动作回放支持最多180,000个模拟步（100分钟模拟时间）；更长操作应拆成多个记录。

剪切沿物理网格边发生，每次完整闭合最多提交一次；再次剪切前需重新张开。离开组织后再移动到下一处，避免闭合工具在组织中横向拖动。当前网格约 5 mm，不支持任意精细器官切割。

### 曲面试件的进出路径

进入曲面内部抓持点时，应从前侧自由边进入，沿曲面拱形逐步接近。抓持并抬升后，先保持抬升高度、等待钳口充分张开，再沿抬高的原路径退回自由边，最后移回初始位置。不要从曲面内部直接向初始位置走一条穿过拱形组织的直线。

这个区别已经在测试中测量：内部抓持、抬升本身正常，但直接走直线撤回的诊断路径出现约 **0.4928 mm** 的物理节点穿入钳口深度；改为“自由边进入—沿拱形接近—抓持并抬升 4 mm—保持高度完全张开—沿抬高曲线路径退出”的450个状态验证路径，测得该项深度为0。最终验收同时核对对应二进制与完整测试证据；单次路径检查不代表一般碰撞覆盖。

本阶段验收上限是 **0.15 mm 的采样物理节点深度**。它只检查物理节点在钳口盒内的穿入量，不保证5 mm网格节点之间的整个三角面都不相交，也不保证任意拖动路径均不穿插。测试通过说明规定操作范围成立；更通用的碰撞覆盖属于后续工作。

## 记录与证据

`Logs/` 保存启动和运行日志，`Sessions/` 保存本次启动拥有的原生记录目录。正常退出会等待原生进程完成写入；请等待启动器结束再移动文件。若启动器提示强制退出，该次未完成记录不能当作完整数据使用。UE 会话和快照的准确路径可在游戏日志中查看。原生记录包含动作、完整状态与配置元数据，UE 展示状态另含相机和显示状态身份。它们是工程状态数据，不是经过实物标定的受力测量。

交付验收证据位于 `Verification/`：两个试件各 600 秒模拟时间的持续测试、五次重复轨迹比较、原生与 TCP 回归、UE 输入与快照投影、独立打包运行、截图和会话记录。是否通过以及实测指标以该目录中的 JSON 为准。`验证记录.md` 给出证据索引，ZIP 在新目录重新解压运行的报告另存于 `output/Phase4/archive-relocation-verification.json`。

```powershell
& .\StartTrainer.ps1 -Specimen curved
# 重新启动后载入以前保存的动作，再在界面按 F6 回放：
& .\StartTrainer.ps1 -ReplayRecording 'C:\MySessions\session-123-actions.json'
& .\StartTrainer.ps1 -LapPhase4Test -LapAutoExit -LapCaptureDir 'C:\Temp\EndoForgePhase4'
```

本阶段的完成意味着基础形变系统达到规定工程门槛。胆囊与周围组织的连接、正式美术与物理表面匹配、参考视频调参，以及具体场景需要的组织接触仍属后续任务。没有临床有效性、硬实时性能或真实力反馈的验证结论。
