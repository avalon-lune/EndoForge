# EndoForge 第七阶段：共同模型、材质与腔镜呈现

项目作者与维护者：Avalon。

完整解压后运行 `StartTrainer.cmd`。启动器会运行随包提供的原生物理服务，
再启动第七阶段 UE 场景。无需安装 UE 编辑器、Blender 或 Python。
需要支持本阶段 DX12 / SM6 / 硬件光追的显卡和驱动；实际性能以测试报告为准。

等待场景准备完成，再按 `2` 接近左侧抓持位置，按 `F` 闭合；`3` 接近右侧位置，
`C` 切换器械。方向键或鼠标右键拖动控制位置，`W/S` 或滚轮调整高度，
`Ctrl` 精细移动，`Ctrl+滚轮` 发出 0.2 mm 位移目标。`F` 切换闭合，
`Space` 临时闭合，`T/G` 沿器械轴线移动，`Q/E` 旋转。

鼠标中键拖动观察，`PageUp/PageDown` 改变观察距离，`Home` 恢复视角。
`R/1` 重置，`F5` 录制，`F6` 回放，`F7` 保存冻结快照，`F10` 退出。
关闭程序前结束录制。碰撞保护阻挡钳口张开时，先撤回再尝试释放。

本版本记录了新的碰撞搜索和并行执行配置。旧阶段的动作文件请使用对应的
旧交付包回放；本版本需要重新录制。不同机器的实际线程配置不一致时，
严格回放校验也可能拒绝记录，程序会明确提示，不会静默使用不匹配的配置。

本阶段沿用第六阶段原生物理求解方法，修正肝脏物理表面与对应显示模型，
并对新几何重新执行物理验证，同时改进原创模型、表面材质、腔镜照明与外观记录。
显示细节不代表额外物理分辨率。
胆囊与肝床之间的浅色连接层用于显示原生附着约束，不是独立的膜组织有限元。
胆管、血管仍为定位模型；当前外观属于改进后的工程解剖场景，尚未达到真实手术影像的拟真程度。
肝脏和局部腹腔仍主要为静态结构，不支持胆囊解剖切开、缝合或临床标定力反馈。
阴影与高光来自实际渲染；配套几何法线不包含材质法线贴图的微结构。

源代码位于 `Source/`，模型位于 `Assets/Phase7/`；校验结果以随包
`Verification/verification-index.json` 和压缩包旁的最终验收文件为准。
原始老师参考图片不会作为程序贴图或公开素材随包分发。
