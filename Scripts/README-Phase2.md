# LapTrainer 第二阶段测试包

本程序是使用 UE 5.7.4 和 SOFA 26.06.00 的腔镜训练工程原型，呈现精细工程器械与软组织训练垫。本版尚不是器官场景或临床内镜画面的写实复现。二期输出独立保存在 `output/Phase2`，一期交付保留在 `output/Phase1`。材料与接触参数仍需实物标定及医生评审。

## 启动与退出

1. 完整解压到可写的本地目录，保留 Engine、LapTrainer、Physics 和 Source 等文件夹。
2. 双击 `StartTrainer.cmd`，等待本地 SOFA 服务就绪以及 UE 窗口出现。
3. 使用键鼠操作虚拟器械。无需安装 UE 编辑器或 Blender，无需真实器械。
4. 按 F10 或关闭游戏窗口结束；启动器只清理本次启动的物理服务。

本版本使用 Windows x64 和 DirectX 11。如提示缺少 Visual C++ 运行库，可运行 `Engine/Extras/Redist/en-us/vc_redist.x64.exe`。请不要同时打开多个二期实例；二期物理服务独占 127.0.0.1:47322，与一期使用的 47321 分开。检测到二期端口已有监听器时，启动器会明确报错，不会终止其他进程。

## 第一次抓持、牵拉和释放

1. 等待物理连接成功，按 `2` 选择前缘抓持预设。程序会复位组织，并把张开的钳口移至训练垫前缘外侧，自动设置 90° 轴向旋转。
2. 按 `Tab` 切换到俯视。保持当前高度，用 `Ctrl` 加方向键缓慢从垫外向内接近约 9 mm，让自由前缘进入两瓣钳口之间。方向键按相机画面方向移动；不要把它们当作固定世界 X/Y 方向。
3. 停约 1 秒，再按住 `Space` 至少约 1.6 秒，等待出现 `GRIP`。单纯从组织顶面闭合不一定能夹住；需要两瓣内侧分别接触组织。
4. 保持 `Space`，用 `Ctrl+W` 慢慢抬高约 5–8 mm，观察组织随钳口变形。首次尝试先小幅牵拉。继续拉远可能出现 `SLIDING` 并自然滑脱。
5. 松开 `Space` 张口，观察释放与回弹。滑脱后也要先松开空格、让钳口张开，再重新抓持。需要从头开始时按 `2`，回到一般初始位置时按 `R`。

该前缘路径已通过 UE 软件输入联调；人的鼠标手感与实际操作便利性仍需试用确认。需要完整重复画面时，使用下方二期专用自动验收入口。

| 操作 | 键鼠 |
|---|---|
| 在水平面上移动钳尖 | 按住鼠标右键拖动，或方向键；方向随相机画面变化，高度由独立按键控制 |
| 升高 / 降低 | `W` / `S`；滚轮每格约 1.8 mm |
| 沿杆身插入 / 撤出 | `T` / `G` |
| 绕杆轴旋转 | `Q` / `E` |
| 闭合 / 张开 | 按住 / 松开 `Space` |
| 精细移动 / 快移 | `Ctrl` / `Shift` 加运动键；后端仍限制实际器械速度 |
| 表面接触预设 / 前缘抓持预设 | `1` / `2`；都会复位组织与张开钳口 |
| 复位 | `R` |
| 视角 | `Tab`：内镜、俯视、侧视、钳口近景依次循环 |
| 帮助 / 释放鼠标 | `H` / `Esc`；右键重新捕获鼠标 |
| 退出 | `F10` 或关闭窗口 |

## 物理模型与边界

- SOFA 驱动 120 × 80 × 12 mm 训练垫，物理网格为 351 节点、1,152 个四面体，固定后缘 39 个节点；UE 根据返回的位置显示组织与钳口。
- 共旋转线弹性有限元，杨氏模量 3,500 Pa、泊松比 0.35、总质量 0.1152 kg；关闭重力。材料均匀且各向同性，阻尼为数值设置，尚未描述真实组织的黏弹性、各向异性或近不可压缩性。
- 双钳口与组织使用原生 SOFA 接触及库仑摩擦约束，摩擦系数 0.65；托盘使用同一约束体系的静态三角平面支撑。夹持与滑动来自接触求解；本版不使用一期的近距离抓持弹簧。
- 物理以固定 `1/30 s` 步长运行，按真实时间目标调度；渲染独立，目标为 60 FPS。高负载时个别求解步可能超过 33.33 ms，本版不承诺硬实时或力反馈频率。实测耗时见 `Verification` 的报告。
- 器械通过固定穿刺点运动，插入距离限制为 120–300 mm，摆动锥限制为 32°；实际移动速度上限为 20 mm/s。橙色目标标记可能领先于实际钳尖，表示命令和受约束后的实际姿态有差异。
- 相向内侧接触且总钳口载荷超过 0.5 N 后暂停继续闭合；这只是工程夹持控制规则。两瓣同时碰到同一顶面不会被判为夹住。继续牵拉可能滑移、失去夹持；张口后才允许再次抓持。

钳口碰撞采用分段长方体包络，长 14.5 mm、宽 2.5 mm、厚 1.4 mm；可见倒角、凹齿和浅槽位于包络内。接触分离偏置为 0.4 mm，局部可能看见细小间隙。组织显示细分只改善平滑度，不增加物理网格精度。当前只验证双钳口的碰撞，不包含完整杆身碰撞、组织自碰撞、剪切、缝合、撕裂、出血、流体或力反馈。

总接触载荷超过 2 N、采样重叠超过 2 mm 或单元体积比低于 0.08 时，系统会拒绝该候选步并回退。接触过载会松开钳口；质量异常会停下并要求复位。出现保护提示时先松开空格，必要时按 `R`。这些数值是稳定性保护参数，不是组织损伤阈值或医疗安全限值。断线或 0.5 秒没有有效控制消息时，物理服务也会停止移动并张口。

## 视觉表现

- 组织训练垫采用程序化柔和色差、细微纤维、湿润表面粗糙度和小幅度微法线。
- 器械采用手术不锈钢拉丝表面与深色绝缘套，训练托盘与垫底衬分别使用独立材质。
- 这些纹理和微法线只影响着色，不移动顶点，不替代组织力学或钳口碰撞，也不是患者组织影像或病理信息。

## 自动验收与日志

二期专用测试入口：

```powershell
& .\StartTrainer.ps1 -LapPhase2Test -LapAutoExit -LapCaptureDir 'C:\Temp\LapTrainerPhase2'
```

实际测试步骤、通过条件和结果以随包 [Verification 目录](Verification/) 为准。运行后的新日志位于 `Logs`，新截图位于 `-LapCaptureDir` 指定目录。自动测试不等同于用户用实体键鼠完成交互验收，也不证明临床有效性。

每次训练另以约 10 Hz 记录会话 CSV，通常位于 `LapTrainer/Saved/Sessions`，文件名以 `session-` 开头并包含 UTC 时间与唯一标识。准确路径可在游戏日志中搜索 `LAP_SESSION telemetry=`。记录包括命令与实际钳尖位置、开合与旋转、接触数、总接触载荷、穿透毫米数、滑移毫米数、求解耗时、夹持状态和复位编号；日志按秒缓冲写入，并在断开或正常退出时刷新。CSV 的 `contact_force_n` 与 `grip_force_n`、通信状态中的 `force_n` 都是总接触载荷的相关字段，不是净反力。

反馈操作问题时，请提供对应会话 CSV、`Logs` 下的游戏与物理日志，以及复现步骤或截图。

当前以 N 显示的接触指标，是各个接触约束在单步内的平均力大小之和，即“总接触载荷”；它不是各方向相加后的器械净反力，也不是单侧钳口的夹紧法向力。该值根据当前隐式积分配置，将约束冲量除以时间步长后计算。总接触载荷及其他接触指标仍是未经实物标定的模型值，不是实际器械测量值，也不是医疗安全限值。

显示载荷只统计钳口接触，排除托盘约束。穿透指标是指定采样点的几何重叠量，不是连续表面绝对无交叠的证明；滑移量跟踪抓持时的材料点在钳口切平面中的相对偏移，不是累计路径长度。详细定义与数值保护见 `Source/Physics/README.md`。

包内只保留 `Verification` 中受控的验收证据，不预装开发测试产生的个人会话、Saved 缓存或运行日志；新的会话目录会在运行后生成。

二期只使用 `-LapPhase2Test` 进行自动验收。它经 UE PlayerController 注入输入，由正常交互代码读取，并检查 SOFA 返回的接触与夹持状态。原有 `-LapAutoDemo` 和 `-LapKeyTest` 仅保留为旧调试入口：前者是预定工具轨迹演示，后者含一期抓持假设，不能用来判定二期通过。每次只选择一种自动模式；不传自动模式参数时正常手动操作。

## 依赖、源码和重建

- `Source/Physics`：物理服务源码、下载/构建脚本、依赖版本与校验信息、网络测试。
- `Source/LapTrainer`：UE 工程、配置、资产、C++ 源码与资产生成脚本，不含可重新生成的编译缓存。
- `Source/Dependencies/sofa-v26.06.00-source.zip`：对应 SOFA 源码；上游地址为 https://github.com/sofa-framework/sofa/tree/v26.06.00 。
- `Licenses` 及 `Physics`：第三方许可和声明。
- 开发重建需要 UE 5.7.4、Visual Studio C++ 工具链及物理服务 README 中指定的依赖；普通运行不需要安装这些开发工具。
- `package-manifest.json` 记录分发文件的大小和 SHA-256，不包含运行后新增日志。
