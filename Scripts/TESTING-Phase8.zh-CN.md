# EndoForge 第八阶段试用说明

本版本用于项目一、项目二分流前的共同基础测试。实际通过项目、指标和文件
身份以随包的验证报告为准；本说明不替代验证报告，也不代表临床或导师验收。

## 启动

完整解压后双击 `StartTrainer.cmd`。运行包自带物理服务，不要求安装 UE、
Blender 或 Python，也不要求实体器械。等待右侧物理连接和准备状态正常。
需支持 DX12、SM6 和硬件光线追踪的显卡；性能结果只适用于报告中的实测机器。

需要在 UE 中编辑时，使用 `Source/Prototype/LapTrainer/LapTrainer.uproject`。
先按 `Source/Scripts/README-Phase8.md` 启动物理端，再用开发启动器打开编辑器；
只双击项目文件不会自动选择第八阶段或启动物理服务。

## 一次完整操作

1. 按 `2`，等待左侧器械到达预置抓持位置，再按 `F` 闭合。按方向键或按住
   鼠标右键拖动，观察胆囊随接触摩擦产生形变。`Ctrl` 为精细输入。
2. 用 `Ctrl + 滚轮` 做每次 0.2 mm 的上下微移；`W/S` 上下移动，`T/G` 沿
   器械轴进退，`Q/E` 滚转。避免用快速大幅移动代替精细抓持。
3. 按 `3` 到达右侧预置位置，`C` 切换当前器械，`F` 控制各自闭合。验证一只
   保持、另一只牵拉，以及两只同时保持。摩擦不足时允许滑移，并非把组织焊死。
4. 再按 `F` 释放。若静态肝脏阻挡了张开，先沿来路撤回后张开。`R` 或 `1`
   重置。中键拖动环绕观察，`PageUp/PageDown` 调整距离，`Home` 恢复视角。
5. `F5` 开始/结束记录，`F6` 回放；回放期间实时器械输入被锁定。`F7` 保存
   冻结状态快照。记录开始会从重置状态建立可重复起点。
6. `H` 显示帮助，`Tab` 切换视图，`Esc` 释放鼠标并请求张开，`F10` 退出。

## 重点观察

- 胆囊边缘、近景和斜视角是否平滑；组织与器械表面是否容易区分。
- 血管、颜色和表面细节是否随形变移动；高光可随视角变化，不应被误认为
  固定在组织上的标签。几何法线数据不包含材质法线贴图。
- 精细/普通/快速模式下起步、停止、反向和切换器械是否可控；牵拉、释放、
  回放、重置是否保持物理健康状态。出现安全停机应重置并保留日志。
- 腔体和脂肪是工作区背景，当前不具备通用接触反应。不要把工作区外自由
  穿越解释为已经验证的全器械、全组织碰撞。

## 版本边界

本阶段改进共同模型展示、材质和写实渲染，并保留经验证的物理与记录基础。
四个内部配对检查用于验证 RGB、相机、状态和几何对应，不是两个课题的数据集。
项目一的高光分解/曲率/跟踪和项目二的肠镜场景/跨帧对应尚未开始。
当前仍是理想化合成器官，肝脏为静态，导管和血管为方向标志；不包含完整解剖
分离、缝合、标定后的组织参数或手柄力反馈，不能宣称已经达到真实手术影像
或医学有效性。第三方框架的许可及作者信息见随包许可证。
