# EndoForge 第六阶段：共同基础与画质升级

本阶段完善项目 1／项目 2 分流前共用的操作、场景、渲染和数据能力。仍以胆囊、肝脏和局部腹腔作为验证场景；没有开始肠腔专项建模、完整高光数据集或缝合。实际通过的内容与数值以 `Verification/verification-index.json` 及交付目录中的 `phase6-final-verification.json` 为准。仅有本说明或能启动程序不代表验收通过。

## 启动

完整解压后双击 `StartTrainer.cmd`。运行包无需安装 UE 编辑器、Blender、Python 或 SOFA SDK；键鼠即可操作，不需要实体器械。需要支持 DirectX 12、SM6 与硬件光线追踪的 Windows x64 显卡及驱动。验收机器使用 RTX 5080；其他硬件的帧率不能由本机结果推定。

默认显示分辨率为 1920×1080，使用 DirectX 12。若缺少 VC++ 运行库，可安装包内 `Engine/Extras/Redist/en-us/vc_redist.x64.exe`。启动器使用本机端口 `47329`；占用时会退出，不会关闭其他程序。请从启动器进入，不要直接运行内部游戏 EXE。

启动时会显示场景准备提示，完成后开放器械操作；普通运行与验收使用相同流程。准备期间仍可按 `F10` 退出。若超过 90 秒未准备完成，界面会报告失败，请关闭后重新启动。

关闭窗口或按 `F10` 后，等待启动器完成物理记录写入。初始场景准备耗时单独记录在运行报告中；准备完成后的慢帧仍计入相应运行性能统计，不按帧率高低挑选样本。初始准备不保证后续未见视角或导出模式不再需要准备。

## 键鼠操作

| 操作 | 按键 |
|---|---|
| 左／右夹钳准备位置 | `2`／`3` |
| 切换当前夹钳 | `C` |
| 当前夹钳保持闭合／解除 | `F` |
| 临时闭合 | 按住 `Space`；已用 `F` 锁定时仍需 `F` 解除 |
| 画面方向移动 | 方向键，或按住鼠标右键拖动 |
| 上提／下移 | `W`／`S` 或滚轮 |
| 沿器械杆进退／旋转 | `T`／`G`，`Q`／`E` |
| 精细／快速移动 | `Ctrl`／`Shift` 配合移动 |
| 完全复位 | `R` 或 `1` |
| 开始／停止动作记录 | `F5`；开始时回到确定起始状态 |
| 开始／停止回放 | `F6`；回放时实时移动输入锁定 |
| 保存冻结状态及画面 | `F7` |
| 切换视角／帮助 | `Tab`／`H` |
| 环绕观察 | 按住鼠标中键拖动 |
| 拉远／拉近观察 | `PageDown`／`PageUp` |
| 恢复观察位置 | `Home` |
| 释放两把夹钳和鼠标 | `Esc`；再次右击恢复操作 |
| 退出 | `F10` |

建议先复位，使用 `2`、`F` 完成单钳抓持，在观察接触状态的同时小幅牵拉，再释放。双钳操作使用 `C` 依次控制两把夹钳，各自保持闭合状态。抓持依靠摩擦，超过当前夹持与组织条件可能滑脱；此时张开、重新定位、再抓持。

第六阶段按下 `2`／`3` 时，准备目标会根据当前已接受的组织形变更新一次，并在此次靠近过程中保持该目标。第二把夹钳可因此对准第一把夹钳牵拉后对应的组织位置。后续移动、闭合和牵拉由键鼠输入与接触摩擦决定；本次准备目标的依据记录在 `phase6-ready-targets.json` 中。

## 场景、渲染与物理

本阶段分别处理显示模型和物理模型，具体网格规模、表面绑定方法、接触偏差、空间布局和材质以资产说明及验收报告为准。增加面数并不意味着经过临床解剖或真实组织材料验证。记录的受力来自当前数值模型；无需为显示细节无差别增加所有物理单元。

交付必须记录实际 D3D12／SM6、Lumen 全局光照与反射、硬件光线追踪和近距离高质量阴影是否运行；配置文件中的开关不是唯一证据。验收包含同一冻结状态的全特性画面，以及分别关闭 GI、反射、阴影的对照；重复全特性画面用于估计时域残差。

显示帧率与物理进度分别报告。输入响应是本地键鼠事件到原生物理接受并返回 UE 的时间，不是外部测得的硬件运动到屏幕发光延迟。渲染截图冻结时段不计入连续物理速度。

第六阶段使用现有 SparseLDL 求解器的四线程独立行计算选项加速逆矩阵乘积；材料参数、时间步长和接触阈值保持原定义。数值等价性、完整回归和运行速度分别记录在对应二进制的验收证据中。

夹钳闭合至两侧内表面的法向接触力各达到 0.03 N 后，锁定当时的钳口角度；此后抓持与滑脱由摩擦接触决定。该数值用于工程模型中的抓持判定，不是临床标定的安全组织载荷。打开指令必须等实际钳口分离、接触解除后才显示释放；肝脏边界可能阻挡张开，需要先撤回。原有 20 项回归之外，验收增加 15 项长时间抓持：两把夹钳各自的名义位置与独立的三轴正负 0.1 mm 偏移，以及双钳牵拉。每项包含 60 秒抓持、牵拉后再保持 60 秒、闭合回撤和释放；逐步状态、角速度、力、接触及数值健康检查均保留。新增独立整面几何检查覆盖左钳、右钳和双钳三个名义长保持轨迹；偏移轨迹不宣称经过额外的独立整面几何审计。

接触求解保留逐步收敛误差和物理子步记录；已去除会造成持续抓持缓慢滑移的额外数值柔化。过大的组织单步位移或未充分收敛的接触解会从保存状态细分重算，重试时重建接触缓存；无法通过时停止物理操作，需复位。肝脏对钳口的几何运动限制不作为测得的反作用力输出。

通用自接触、完整腹腔器官互碰、柔性肝脏、血液／胆汁、床面剥离、器官剪切和缝合，只有在对应报告明确验证时才可视为支持。有限路径上的通过不能外推为任意操作都不会穿透。

## 回放与基础数据

`Logs/` 保存程序日志，`Sessions/` 保存原生动作与状态。回放要求匹配模型、材料和配置身份，按节点误差与事件一致性验收；不承诺不同进程逐位相同。

基础双目样例使用同一冻结状态，逐帧保存 RGB、相机 Z 深度（毫米）、世界坐标几何法线、对象 ID、有效掩码、实际渲染三角形和相机参数。几何法线与材质法线贴图不同；深度也不是沿射线的距离。边缘与其他无效像素的规则必须明确，不能按照误差大小挑选有效区域。

真实运行的较高精显示表面必须与输出几何对应。材质、照明、曝光和时域设置随样例记录；深度、法线与对象 ID 使用独立几何审计验证。此处仅提供共同数据接口样例，不是两个课题的完整数据集。

```powershell
& .\StartTrainer.ps1 -ReplayRecording 'C:\MySessions\session-actions.json'
& .\StartTrainer.ps1 -LapPhase6Test -LapAutoExit -LapCaptureDir 'C:\Temp\EndoForgePhase6'
```
