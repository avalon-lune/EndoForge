# EndoForge 第四阶段：碰撞修复与扩展验证版

本版本用于完善原第四阶段的夹钳—组织接触，重点复查曲面内部直线撤回，并增加角度、速度和路径组合。仍是平面／曲面试件，不包含胆囊、腔体建模或缝合。原 `output/Phase1/` 至 `output/Phase4/` 全部保留；本修复版独立放在 `output/Phase4-CollisionFix/`。

最终程序已通过下列原生、协议及实际打包交互测试；ZIP 重新解压运行的独立结果见包外 `archive-relocation-verification.json`，它与实际 ZIP 的 SHA-256 绑定。

本次补齐组织与钳口的边缘接触、修正接触特征过滤，并让剪切重建等状态恢复后的碰撞表面及时跟随物理形状。抓持仍依靠真实接触与摩擦，闭合反馈保留原参数。同时重新检查双器械剪切时的握持。具体实现、最终参数与验收解释见 `Source/docs/PHASE4-COLLISION-FIX.md`。

## 启动与操作

完整解压后双击 `StartTrainer.cmd`。无需 UE 编辑器、Blender、Python、完整 SOFA SDK 或实体器械。支持 Windows x64、DirectX 11；如缺 Visual C++ 运行库，使用包内 `Engine/Extras/Redist/en-us/vc_redist.x64.exe`。

使用本机 `127.0.0.1:47325`。端口被占用时启动器退出，不会停止其他程序。请从启动器进入，不要单独打开内部游戏 EXE。结束会话后等启动器正常退出，再移动会话文件。

## 这次验证什么

原版的一条曲面内部直线撤回路径曾出现约 **0.4928 mm** 物理节点进入钳口的深度。原版通过沿抬高曲线返回来限定操作范围。本次把原失败路线保留为回归用例，不能通过改成绕行路线、放宽阈值或省略失败帧来判定修复。

验收同时保留双试件各 600 秒模拟时间的连续循环、五次轨迹回放、原生／TCP／UE 协议、双器械与剪切兼容、实际打包和重新解压运行检查。新增碰撞矩阵及逐步几何证据位于 `Verification/collision/`，结果与验证范围以 JSON 和技术说明为准。

新增矩阵规定 19 条轨迹，覆盖 60°、75°、90°、105°、120° 滚转角，6／12／18 mm/s 名义运动速度，以及直线、斜线、折线、切向、往返、竖直退出。测试还核对器械实际角度、真实移动和返回直线，不能靠改标签、停住器械或隐藏绕行通过。组合覆盖不是所有角度、速度、路径的穷举。斜角抓持允许稳定保持，也可能发生接触滑脱；需要能正确释放并重新抓持。

已有节点采样上限为 **0.15 mm**。节点检查不能覆盖 5 mm 网格间的整个三角面，因此修复版还需要表面层面的独立检查。有限的角度、速度与路径测试不等于任意运动、连续表面或组织自碰撞的普遍保证。材料、接触和剪切参数仍未经过真实组织标定。

| 最终程序实测 | 结果 |
|---|---|
| 新增碰撞矩阵 | 19／19 通过；7,406 个输出帧（含初始帧）、22,161 个帧间插值样本；节点、整三角面及插值几何的最大测得穿入深度均为 0 mm |
| 原生核心与回放 | 46／46 通过；平面、曲面各五次重复轨迹的最大节点 RMS 为 0；实切后四组物理／碰撞状态向量误差为 0 |
| 平面／曲面连续耐久 | 各 600 秒模拟时间、18,000 步、60 次有效抓持循环；各 9／9 检查通过，保护事件为 0 |
| 协议与剪切兼容 | 第四阶段 TCP 20／20；第三阶段原生 19／19、TCP 19／19、UE 输入 17／17；两阶段 UE 原子协议测试通过 |
| 实际打包交互 | 22／22 通过；曲面直线撤回实际移动 39.309 mm；显示状态节点穿入为 0，保护事件为 0 |
| 补充配置 | 曲面、固定后两排、杨氏模量 30,000 Pa：8／8 通过；100 个固定节点误差为 0；仅验证该配置的短程抓持、牵拉和释放 |

打包交互保存了 12 张操作截图、3 组冻结截图／状态，以及 726 条遥测。该次会话的物理步耗时 P95 为 40.633 ms，运行时另有原生回归任务并行；这不是独占机器的性能基准或硬实时保证。上表的“0”只表示声明测试与几何度量的实际结果，不代表所有路径都不会发生穿透。

`Verification/diagnostics/legacy-collision/` 单独保留旧版失败对照。此次旧包复现接收到 329 个状态、缺少 step 1，独立测得节点穿入约 0.479091 mm、三角面穿入 0.700000 mm。它用于说明原问题，明确不计入修复版通过证据。

## 记录与交付证据

`Logs/` 保存运行日志，`Sessions/` 保存本次启动拥有的原生记录。正常退出会等待写入完成；强制退出产生的未完成记录不能视为完整数据。冻结快照包含对应物理状态、显示网格与相机，不是完整视频／深度／分割数据集。

**旧记录的回放：**旧版动作文件可以载入修复版，但接触模型改变后，同一批动作可能产生不同的形变和受力。要精确复现以前的轨迹，请使用录制时对应的原交付包；在修复版重新求解旧动作属于新的计算。本版本内的录制与回放另有重复性验收。

器械之间的碰撞、杆身碰撞、组织自碰撞及组织之间的接触仍不在本次实现范围。闭合反馈中的数值是仿真控制参数，不是实测手柄力或医疗建议夹持力。

`Verification/验证记录.md` 为验收索引，`verification-summary.json` 为汇总，`package-manifest.json` 保存每个分发文件的大小和 SHA-256。ZIP 在新目录重新解压运行的证明位于 `output/Phase4-CollisionFix/archive-relocation-verification.json`，作为 ZIP 外部记录避免循环哈希。
