# EndoForge 第五阶段：胆囊与局部腹腔

这是新的胆囊形变、肝床附着和双夹钳操作工程场景。模型在 Blender 中原创制作，参考老师提供的两套解剖模型及真实腔镜影像；没有把第三方模型或参考照片复制进交付资产。可编辑模型、生成脚本、物理与 UE 源码随包提供。

## 启动与试用

完整解压后，双击 `StartTrainer.cmd`。运行包无需安装 UE 编辑器、Blender、Python 或 SOFA SDK，也不需要实体器械。需要 Windows x64；如提示缺少 VC++ 运行库，安装包内 `Engine/Extras/Redist/en-us/vc_redist.x64.exe`。默认窗口 1920×1080，DirectX 11。

启动器使用本机端口 `47327`，端口被占用时会退出，不会关闭其他程序。请从启动器进入，勿单独打开内部游戏 EXE。按 `F10` 或关闭游戏后，请等待启动器完成原生记录写入。

单钳试用：按 `2`，等待左夹钳到位，再按 `F` 保持闭合。确认有效抓持后，短按 `Ctrl+W` 缓慢上提，观察胆囊及肝床连接的变化；再按 `F` 释放。

双钳试用：先按 `R` 复位，按 `2` 到位后按 `F` 闭合，再按 `3` 到位后按 `F` 闭合。确认两把夹钳都有效抓持，再用 `C` 交替切换，每把以约 1 mm 的小步上提，初次试用每把累计先控制在约 2 mm。进一步牵拉或另一把保持不动时单侧大幅牵拉可能滑脱；需要张开后重新抓持。分别切换并按 `F` 释放，最后按 `R` 复位。

| 操作 | 按键 |
|---|---|
| 左／右夹钳抓持准备位置 | `2`／`3`，等待实际器械到位 |
| 切换当前夹钳 | `C` |
| 当前夹钳保持闭合／解除 | `F`；两把夹钳各自保持状态 |
| 临时闭合 | 按住 `Space`；若已用 `F` 锁定，需用 `F` 解除 |
| 画面方向移动 | 方向键，或按住鼠标右键拖动 |
| 上提／下移 | `W`／`S` 或滚轮 |
| 沿器械杆进退／旋转 | `T`／`G`，`Q`／`E` |
| 精细／快速移动 | `Ctrl`／`Shift` 加移动键 |
| 完全复位 | `R` 或 `1` |
| 开始／停止动作记录 | `F5`；开始时复位到确定起始状态 |
| 开始／停止回放 | `F6`；回放时实时移动输入锁定 |
| 保存冻结状态和画面 | `F7` |
| 切换视角／帮助 | `Tab`／`H` |
| 释放两把夹钳和鼠标 | `Esc`；再次右击恢复操作 |
| 结束 | `F10` |

## 模型与物理范围

胆囊采用闭合薄壁四面体模型，颈部固定，背侧通过有静止长度的弹性连接附着于固定肝脏。夹钳依赖真实单侧接触和摩擦传递牵拉。当前材料、壁厚、接触和连接参数是可调整的工程参数，尚未通过真实组织实验标定，记录的受力是模型输出。

本阶段围绕局部术野的抓持、牵拉、释放和重复操作验证；肝脏为固定支持体，腹腔背景与网膜是局部视觉结构。尚未实现完整柔性肝脏、囊内液体压力、自接触、胆汁流动、出血、肝床剥离、任意器官剪切或缝合。器械与固定肝脏、器械之间及背景腔壁的通用碰撞限制，不能由胆囊—夹钳接触测试推定成立。请依据验收报告中实际验证的路径和指标判断适用范围。

Blender 预览可使用细分修改器；UE 中的胆囊显示表面与物理边界绑定。纹理和法线贴图用于表面视觉细节，不会被记录为真实几何曲率。模型形态、胆道与血管地标、肝床区域仍需导师或医疗人员审阅；工程验收不等于临床有效性验证。

## 记录与数据样例

`Logs/` 保存程序日志，`Sessions/` 保存原生动作及状态记录。UE 快照和显示状态记录路径写在游戏日志中。模型身份、版本和资产指纹随状态保存；回放必须匹配原始模型与配置。正常退出会等待写入完成；强制终止产生的记录不能当作完整回放证据。

回放按数值精度验收：五次运行的逐帧节点 RMS 偏差不超过 0.5 mm，抓持和释放事件一致。不同物理进程中的浮点累加与摩擦接触迭代可能产生微小差别，负载自适应闭合也可能在阈值附近相差一次更新，因此不承诺逐位一致或受力完全一致；实际测得的 RMS、最大单节点偏差及接触力差保存在验收报告中。

验收导出两段短双目序列，每段至少 12 个独立时间状态、每眼 640×512。每一对左右图来自同一个冻结显示状态，附带实际渲染几何、相机参数、毫米单位的相机 Z 深度、世界坐标几何法线、对象 ID 与有效区域。原始 `.npy` 保留浮点值；深度不是射线距离，几何法线不是贴图着色法线。有效掩码排除了背景及边缘不稳定区域，审计同时报告有效像素比例。

这些是数据接口就绪样例，尚不是老师要求的完整研究数据集。高光分量／无高光成对图、曲率、材料点追踪、真实光学标定、透明折射路径、运动曝光以及肠腔专用场景属于后续扩展。

```powershell
# 载入历史动作；进入后按 F6，由原生服务验证并回放。
& .\StartTrainer.ps1 -ReplayRecording 'C:\MySessions\session-actions.json'
# 运行程序内验收输入路径和双目导出。
& .\StartTrainer.ps1 -LapPhase5Test -LapAutoExit -LapCaptureDir 'C:\Temp\EndoForgePhase5'
```
