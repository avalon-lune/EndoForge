# EndoForge 第九阶段人眼验收说明

这是供你直接观察和操作的候选版本。自动测试通过的项目以随包报告为准；
“人眼验收通过”需要由你确认，不能由测试脚本代替。

## 启动和操作

完整解压后双击 `StartTrainer.cmd`，等待物理服务连接、场景准备完成。
无需实体器械，也无需安装 UE、Blender 或 Python 即可运行打包程序。

1. 按 `2` 到左侧抓持位，`F` 夹持；方向键或按住鼠标右键拖动进行牵拉。
   `Ctrl` 为精细模式，`Ctrl + 滚轮` 每次请求上下移动 0.2 mm。
2. `3` 为右侧抓持位，`C` 切换当前器械。分别夹持，观察一只保持、另一只
   牵拉，以及双器械共同作用。摩擦抓持允许滑移，不会把器械焊死在组织上。
3. `W/S` 上下，`T/G` 沿器械轴进退，`Q/E` 滚转。再次按 `F` 释放。
   若肝脏挡住张开路径，先沿来路撤回再张开；`R` 或 `1` 重置。
4. 中键拖动环绕观察，`PageUp/PageDown` 改变观察距离，`Home` 恢复视角。
   `Tab` 切换视图，`H` 显示帮助，`Esc` 释放鼠标并请求张开，`F10` 退出。
5. `F5` 开始/结束记录，`F6` 回放，`F7` 保存冻结快照。记录从可重复的
   重置起点开始；回放期间实时器械输入锁定。

## 请重点检查这些画面

- **胆囊下缘与远端轮廓**：回到之前指出多边形的近景，左右转动视角，观察
  是否仍有明显直线拼接、尖角、孤立三角凸起或接缝。
- **夹钳接触区**：夹持、微量牵拉、释放各观察一次。矩形钳口形成的局部
  接触压痕应和器械位置对应；大范围轮廓不应出现无来源的尖刺。
- **形变过程**：单器械与双器械动作应连续，血管纹理应跟随同一组织位置，
  松开后应恢复；高光随视角移动是正常的。
- **肝床与周围组织**：观察胆囊和肝床的附着过渡、脂肪起伏、组织间的层次，
  以及颜色、高光是否仍像塑料或规则几何体。
- **操作和回放**：检查精细移动、停止、反向、释放和重置是否跟手；记录
  一段短动作并回放，确认器械与形变的关系一致。

反馈时，最好注明“哪个视角、哪只器械、做什么动作时出现”，并附截图。
画面不合格时应继续修改，不以增加面数或自动测试通过代替视觉结论。
可先打开 `Evidence/visual_gallery.html` 查看实际 UE 前后对比和十个灰模视角。
灰模近景仍可见轻微的远端曲率分区，已保留供你判断，没有宣称所有表面瑕疵消失。

## 当前范围

这是合成局部器官及共同仿真基础。物理输出有明确单位、方向、状态与版本
绑定，但尚未做真实组织参数和手柄力标定；胆囊腔内没有流体压力模型。
肝脏为静态，腔体/脂肪主要提供环境，导管和血管仍为定位标志。
不包含缝合、完整组织分离、通用全器械碰撞或项目一/项目二的专项实现。
随包的四帧输出用于内部坐标对应检查，不是课题数据集。
